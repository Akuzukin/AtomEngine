# 类幸存者《碎星哨站》开发文档（Codex 自动开发用）· GDD v1\.0

# 设计首页

## 项目一句话

玩家操控一名自动开火的哨兵「星屑」，在碎裂星域的尸潮里走位求生——输出交给系统，走位交给玩家。通过局内三选一强化滚出构筑，用局外商店与永久养成把每一局都变成下一局的起点。

## 游玩条件

|维度|取值|说明|
|---|---|---|
|平台与输入|**PC 键鼠 手柄**，|WASD/方向键移动，鼠标指针方向决定索敌与散布参考|
|单局时长|**20–30 分钟**，标准通关 20 分钟|前 15 分钟承压，后 5 分钟进入割草窗口|
|玩家关系|单人离线|无联机，无排行|
|题材美术|**3D 简约风**（低多边形几何）|程序化占位图形即可，可替换|
|技术目标|使用自制引擎实现|供 Codex 直接产出并验收的规则集：`survivor-v1`|

## 核心承诺

输出是自动的，**走位是唯一主动压力杠杆**。玩家的全部判断落在四件事上：往哪走、贴不贴怪、何时穿过尸海、要不要冒风险去捡关键经验。代价是挨打或丢掉伤害窗口，收益是清怪更快、构筑成型更早。

## 设计支柱

1. **危险必须先可读。**冲锋怪有 1\.0 秒前摇闪光与音效，精英与 Boss 出场有屏震和文字预告。无预告随机秒杀不进范围。

2. **升级选择是稀缺决策。**每次升级三选一围绕"补当前短板 or 深化流派"给出可比较代价，不做纯数值加三条填空。

3. **失败可归因、可恢复。**死亡结算展示本局构筑回顾与承伤来源占比；永久成长只增不减，金币死亡保留，不产生无法恢复的贫困。

4. **后期用构筑密度取代数值堆叠。**伤害类强化约占四成，武器进化提供倍增而非线性加法，20 分钟进入割草窗口。

## 核心动词

移动走位（WASD）、瞄准（鼠标指针）、拾取（自动磁吸）、选择强化（1/2/3 或点击）、施放主动（空格）、引爆碎尸（E）、暂停与放弃（Esc）。

## 循环一句话

清怪获得经验与金币 → 升级三选一重构武器与被动 → 波次压力升级迫使重新走位 → 伤害与生存滚动提升 → 在第 15–20 分钟承压点死亡，或撑到 20 分钟胜利结算。

## 范围与关键结论

- P0 覆盖单武器主流程、三选一强化、波次、精英与 Boss、商店、局外养成、特效反馈。

- 非目标：联机、每日任务、赛季、剧情演出、内购付费。商业形态为单机休闲，不接付费线。

- 关键数值已复算（经验曲线 / 金币账本 / DPS–HP–TTK），口径见 §8\.4；规则集标识 `survivor-v1`，正文、配置、测试与 Demo 共用同一版本。

# 玩法走读

玩家在「裂谷站台」出生，身后补给舱弹出脉冲枪。第一波碎石虫从地图东侧涌来，自动脉冲枪以每秒 4 发的节奏自行开火，玩家用 WASD 绕弧线移动，让弹幕吃满聚团的虫群。第一只虫爆开，溅出两枚青色经验宝石，在 120 半径内自动飞向玩家。

攒满一级，屏幕冻结，弹起三张强化卡：**\+20% 攻速**、**新武器「月刃」**、**\+15% 移速**。玩家按 2 选月刃——它绕体旋转切近身怪，范围短，代价是必须贴上去、更易被围。90 秒时第一只冲锋怪登场，脚下红光前摇 1 秒，玩家提前横移躲开，利用它冲刺后 0\.6 秒的硬直反向贴脸，月刃把它切碎，掉出 6 经验和 0\.3 金币。

第 5 分钟 Boss「裂隙守卫」出现，屏震、血条上弹，前方射线蓄力。玩家保留的空格主动技「冲击波」在它蓄力完成前打断一次，再用磁吸收掉爆裂者炸开的一地经验。途中地图刷新一座补给站，玩家花 60 金币买一瓶恢复剂回满 40 生命。15 分钟后尸潮密度翻倍，玩家靠「脉冲枪＋月刃」的贴脸爆发构筑撑住——伤害类强化已把 DPS 抬到割草量级。20 分钟倒计时归零，结算界面弹出构筑回顾与金币入账，玩家回到主菜单，把金币投入永久强化树，为下一局铺路。

# 玩法架构

## 三层循环与传递物

瞬时层玩家持续做走位判断并读取环境；单局层把走位成果转化为构筑与胜负；长期层用结算货币喂养商店与养成，再抬升下一局起点。三层之间传递的分别是：伤害窗口与生存（瞬时→单局）、金币与星辰（单局→长期）、更强的初始属性与解锁内容（长期→单局）。

## Game Flow

从启动到下一局的完整状态流转：启动 → 主菜单 → 局前准备 → 单局战斗 →（暂停可逆）→ 结算 → 返回主菜单。暂停不清空本局进度，恢复点精确到帧。

# 核心机制

## 玩家与输入

玩家为半径 22 的圆形，出生生命上限 100，移动速度 3\.2 单位/秒，地图尺寸 2400×1600 带边界碰撞。鼠标指针方向作为索敌与武器散布的参考方向；无指针输入时按最近敌人自动瞄准。

|玩家状态|进入事件|结算|退出|
|---|---|---|---|
|idle / moving|方向键输入|按移动速度位移|松开或施放|
|active|空格|施放主动技能|技能结束|
|hurt / invuln|受到可闪避伤害|扣生命，0\.35s 无敌|无敌结束|
|dead|生命 ≤ 0|进入结算 RESULT|返回主菜单|

## 自动攻击与武器系统

武器是自动行为的载体：冷却、射速、弹速、伤害、穿透、目标数与散布构成可配置对象。每种武器有一个"叠满进化"的终点——叠满 5 级后可选择一条进化分支（倍增或改机制），这是后期构筑密度的来源。

|武器|行为|基准伤害|攻速|特殊|进化分支|
|---|---|---|---|---|---|
|脉冲枪|朝索敌方向连射|8|4 发/s|基础武器|双管 ×2 / 加穿透|
|月刃|绕体环绕|6|2 周/s|近身|剑刃风暴 / 提速|
|霰弹|5 发散射|5×5|1\.2/s|贴脸满伤|\+2 弹头 / 增距|
|光束|直线穿透|15|0\.8/s|穿透 N 目标|加穿透 / 加宽|
|飞剑|追踪最近目标|10|1\.5/s|必中|分裂 ×3 / 提速|
|黑洞|原地聚怪并持续伤害|4/s|持续|控制|扩大范围 / 加伤|
|雷暴|环形 AOE|20|0\.5/s|范围|加大范围 / 带电|

**边界例：**子弹命中多个目标时，穿透数在每帧结算前扣减，穿透数降到 0 时该子弹销毁；同一子弹跨帧不得对同一敌人重复结算（去重记录随子弹生命周期销毁）。

## 经验、升级与局内强化（三选一）

经验宝石磁吸后累计，升到满级所需经验为 `exp_next(L) = floor(15 × 1.12^(L-1))`，20 分钟约升至 35 级（累计所需约 6460–10243）。升级时冻结战斗，从强化池抽取 3 张卡片，按 1/2/3 或点击选择。

|强化类型|效果|叠层规则|示例值|
|---|---|---|---|
|新武器|解锁副武器槽|同武器不重复|月刃、雷暴等|
|武器升级|提升伤害/攻速/弹数|叠满 5 级可进化|\+20% 伤害|
|被动属性|攻击%、移速、拾取范围、生命上限、护甲、攻速|每类可叠上限|\+15% 移速|
|主动升级|缩短冷却 / 增强主动|逐级|冷却 −15%|

稀有度权重随等级抬升：0–4 级 白 80 / 蓝 18 / 紫 2；5–14 级 白 55 / 蓝 32 / 紫 12 / 橙 1；15 级起 白 35 / 蓝 38 / 紫 22 / 橙 5。已满级的强化从池中移除，避免空升级；伪随机保证三次候选中至少出现一张与当前构筑协同的卡片。强化池、稀有度与候选分布分开计数，取"实际选择"口径做统计。

## 波次系统与敌人

出怪速率为配置项：0–5 分钟 2 只/s、5–10 分钟 2\.5、10–15 分钟 3、15–20 分钟 3\.5。敌人基础生命随分钟成长：`HP = 12 × (1 + 0.30 × 分钟)`。精英每 90 秒刷一只，Boss 每 5 分钟刷一只，存活至 20 分钟判定胜利。

|敌人|行为|基础生命|经验|金币|备注|
|---|---|---|---|---|---|
|碎石虫|直线追踪|12|2|0\.1|基础单位|
|冲锋怪|1\.0s 前摇后冲锋|20|6|0\.3|前摇红光可读|
|爆裂者|靠近后自爆|10|3|0\.2|死亡溅射|
|治疗虫|为友军回血|25|4|0\.4|优先清掉|
|精英|专属技能＋血条|HP×8|40|10|90s 一只|
|Boss|多阶段技能|HP×60|150|70|5 分钟一只|

敌人状态机：`spawn → seek → chase/attack → hit → die`。被击杀后按归属（最后一击）结算掉落与任务进度，同一敌人跨帧只结算一次。

## 生命、护甲、恢复与失败

生命上限 100，护甲按百分比减伤；恢复剂回 40 生命（上限触顶不溢出）。死亡后进入结算：展示本局构筑回顾、击杀数、承伤来源占比与金币入账，不产生可永久丢失的资源。

## 主动技能与引爆

空格施放主动技能（初始「冲击波」，能量条随击杀积累）；E 键引爆地面碎尸，造成一次范围伤害。主动技能冷却受主动升级影响。边界：能量不足、无碎尸可引爆时输入被规则拒绝并给出明确反馈（不吞按键）。

## 拾取与磁吸

经验宝石磁吸半径 120，金币拾取半径 40（自动）。拾取按每帧结算一次，同一掉落物不重复入账。

# 商店系统

经济在"单局内消费"与"跨局留存"两条流上分开：经验只在单局内烧成构筑，金币与星辰跨局积累、投入商店与永久养成。下方为完整经济与成长流。

## 局外商店（主菜单）

商店消费金币与星辰，是跨局货币的主要出口。永久强化定价 60–700 分档，武器解锁 300–800，消耗品 40–150。单局净收入约 809 金币，玩家 1 局可购数个基础强化，4–5 局解锁一个高级项，避免一次买穿。

|货类|内容|货币|定价|
|---|---|---|---|
|永久强化|属性加点（攻击/生命/攻速/拾取/护甲）|金币|60–700 分档|
|武器解锁|解锁新武器进入局内强化池|金币|300–800|
|消耗品|局内起始补给（恢复剂、护盾、一阶段移速）|金币|40–150|
|稀有解锁|角色切换、传说强化|星辰|50–500|

## 局内补给站

每 4 分钟地图刷新一座补给站，玩家可花金币购买恢复剂、临时移速或一次性强化；补给站限购一次，售罄后消失。

## 货币与刷新规则

金币来自击杀与结算、死亡保留；星辰仅来自精英与 Boss。商店货架固定陈列＋每日不刷新（无运营时间线），确保 Codex 单机实现无服务器依赖。

# 局外养成

## 永久强化树

属性加点树逐级解锁，点满当前节点开启进阶节点；每次加点成本递增（60/150/350/700），成长只增不减。加点效果同时作用于所有局的初始属性。

## 武器与被动解锁

武器解锁后进入局内强化池候选，被动解锁扩充三选一的属性池。解锁是单次消费，解锁后永久生效。

## 角色切换

星辰解锁不同哨兵，各带不同初始属性与初始武器，改变每局起点但共享永久强化树。

## 成就系统

成就记录里程碑（首次通关、单局击杀数、构筑组合数），奖励少量金币，作为额外的跨局推进信号。

## 特效清单

- **命中**：弹着点 4 帧闪白＋0–9 点伤害数字，暴击黄色大数字。

- **击杀**：尸体碎片粒子爆散，经验宝石带磁吸拖尾飞向玩家。

- **升级**：全屏 200ms 闪光＋光柱，弹三选一卡。

- **精英/Boss**：出场屏震＋血条上弹＋文字预告；蓄力射线前置高亮。

- **环境**：背景层级视差，3D 简约几何体随走位轻微倾斜。

- **主动**：冲击波扩散环、引爆碎尸橙色爆闪。

## 性能预算

所有子弹、敌人、粒子与掉落走对象池，粒子单屏上限 1200、子弹上限 400；固定时间步 60Hz 更新＋requestAnimationFrame 渲染；同屏敌人上限 600，超出按出生顺序淘汰。降级策略：粒子数过半时先减命中闪白再减碎片。

# 用于 Codex 自动开发的可执行规格

## 技术栈与运行环境与渲染细节

动态时间步更新、渲染分离，暂停时停止 update 但保留渲染。可使用生成的纹理素材，丰富UI细节，丰富粒子效果（可在引擎端构建粒子系统的编辑器）

## 输入映射

|输入|动作|实现要点|
|---|---|---|
|W / A / S / D 或方向键|移动|向量归一化，边界碰撞|
|鼠标指针位置|瞄准/散布参考|无输入时最近敌自动索敌|
|1 / 2 / 3 或点击|选择强化卡|升级暂停状态内生效|
|空格|施放主动技能|受能量条限制|
|E|引爆碎尸|无碎尸时拒绝并提示|
|Esc|暂停 / 恢复 / 放弃|暂停不丢帧进度|

## 数据与配置结构

所有数值与规则集中于配置对象，正文、测试与 Demo 引用同一 `ruleset: survivor-v1`。核心表结构：

## 状态机与事件顺序

全局状态机：`BOOT → MENU → PREP → RUN → (PAUSE ⇄ RUN) → RESULT → MENU`。局内同帧结算顺序固定为：输入与移动 → 武器冷却与子弹生成 → 子弹移动与碰撞 → 命中伤害 → 敌人死亡与掉落 → 经验磁吸 → 经验累计触发升级（冻结）→ 主动/引爆 → 敌人攻击玩家 → 受击/无敌 → 死亡判定。跨帧事件用唯一事件身份去重，保证一次结算。

## 实现优先级 P0 / P1 / Non\-goals
